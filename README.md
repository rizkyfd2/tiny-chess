A chess engine in 4 KB of Python 3.13, standard library only. Alpha-beta over a
10x12 mailbox board with a transposition table, quiescence search, null-move
pruning, late move reductions, killer and history ordering, and a tapered
material/piece-square evaluation. It searches a fixed node budget per move and
never reads a clock, so every game replays move for move.

`main.py` is the packed entrypoint (`makefun compress` of `engine.py`, the
readable source kept beside it).

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
